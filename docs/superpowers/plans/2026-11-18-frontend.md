# frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Next.js app in `services/frontend` (port 3000) that lists farms and plots and shows each plot's irrigation plan: today's answer with a soil gauge, a tappable 7-day bar chart, stale and error states, and a services status line.

**Architecture:** App Router server components fetch everything through typed fetchers in `src/lib/` (no-store, timeouts, result types instead of throws). The only client component with state is `WeekBars`, which receives the plan as props and switches the day-details panel. Pure helpers (`format.ts`, `plan.ts`) carry the copy and math rules and are unit-tested with Vitest.

**Tech Stack:** Next.js (current, App Router, TypeScript, `src/` dir), Tailwind CSS, shadcn/ui, `next/font/google`, Vitest. Node 25, npm.

**Spec:** `docs/superpowers/specs/2026-11-18-frontend-design.md` (mockup: `.superpowers/brainstorm/3872-1794993513/content/plot-page-v2.html`).

Paths are relative to `services/frontend` unless they start with `docs/` or `CLAUDE.md`. Branch `p2`. Use the frontend-design skill while building the UI tasks.

## Global Constraints

- The browser never calls registry, weather or planner. Only server code in `src/lib/` does, with `REGISTRY_URL`, `WEATHER_URL`, `PLANNER_URL` from `.env.local`; `.env.example` committed.
- No other pages or features than `/`, `/plots/[id]`, not-found and loading.
- Tokens exactly as the spec's table (sky `#EEF3F5`, surface `#FFFFFF`, ink `#18211F`, muted `#4A5755`, water `#1F6FB2`, soil `#7A5230`, refill `#E0A100` on `#FFF4D6`, up `#2E8B57`, down `#C0392B`); one family, Atkinson Hyperlegible Next (fallback Atkinson Hyperlegible); sentence case; no shadows; visible focus; reduced motion respected.
- "No irrigation today" / "none" only when the planner returned `run_minutes: 0`.
- Timeouts: registry 5 s, planner 25 s, health 2 s; every fetch `cache: "no-store"`.
- `npm run build`, `npm run lint`, `npm test` pass; `node_modules/`, `.next/`, `.env.local` never committed.

## Review Focus

1. **Planner slow or unreachable** → error panel "Planner service is not answering", never a blank page or an endless spinner. Test: `describePlanError` cases for `{kind: "unavailable"}` (Task 2) + live check with the planner stopped (Task 5).
2. **Plan shorter than 7 days** (season ends inside the window) → fewer bars plus "The season ends on …; the plan stops there." Test: `seasonEndNote` (Task 2).
3. **A week of all zeros** → bars all flat "none", no division by zero in bar heights. Test: `barHeights([0,0,0])` (Task 2).
4. **Long runs** (`run_minutes` 1500) → "Water for 25 h" and bar label "25:00", nothing overflows at 375 px. Test: `formatDuration(1500)`, `formatClock(1500)` (Task 2); visual check (Task 5).
5. **Odd plot id in the URL** (`/plots/%2E`, unknown id) → not-found page, not a crash. Test: live check (Task 5).

### Task 2: Data layer and pure helpers

**Files:**
- Create: `src/lib/types.ts`, `src/lib/fetch-json.ts`, `src/lib/registry.ts`, `src/lib/planner.ts`, `src/lib/format.ts`, `src/lib/plan.ts`, `src/lib/format.test.ts`, `src/lib/plan.test.ts`, `src/lib/planner.test.ts`

**Interfaces:**
- Consumes: `getConfig()` (Task 1).
- Produces:
  - `types.ts`: `Farm {id, name}`, `Plot {id, farm_id, name, area_m2, crop_id, planting_date, soil_id, row_spacing_m, emitter_spacing_m, emitter_id, lat, lon}`, `Crop {id, name}`, `PlanDay {date, et0_mm, rain_mm, kc, etc_mm, irrigation_mm, litres, run_minutes, bucket_end_mm, stale}`, `Plan {plot_id, crop_id, planting_date, season_end, bucket_capacity_mm, threshold_mm, fetched_at, stale, days: PlanDay[]}`, `FetchError = {kind: "not_found"} | {kind: "unavailable"} | {kind: "problem"; status: number; code: string; detail: string}`, `Result<T> = {ok: true; data: T} | {ok: false; error: FetchError}`.
  - `fetchJson<T>(url: string, timeoutMs: number): Promise<Result<T>>` — no-store; network error/timeout/non-JSON/5xx without problem body → `unavailable`; 404 → `not_found`; other non-2xx with problem+json → `problem`.
  - `registry.ts`: `getFarms()`, `getPlots()`, `getCrops()`, `getPlot(id)`, `getFarm(id)`, `getCrop(id)` — 5000 ms; ids `encodeURIComponent`-ed with `.` → `%2E`.
  - `planner.ts`: `getPlan(plotId: string, days = 7): Promise<Result<Plan>>` — 25000 ms.
  - `format.ts`: `formatDuration(min)`, `formatClock(min)`, `formatLitres(n)`, `formatDayShort(iso)`, `formatWeekday(iso)`, `formatDayLong(iso)`, `formatAge(fetchedAtIso, now: Date)`, `formatMm(x)`.
  - `plan.ts`: `describePlanError(e: FetchError): {title: string; text: string} | "not_found"`, `gauge(plan): {water: number; refill: number}` (fractions 0–1 of capacity, clamped), `barHeights(minutes: number[]): number[]` (0–1, largest = 1, all-zero → all 0), `heroSubline(day: PlanDay): string`, `seasonEndNote(plan, requestedDays = 7): string | null`.

**Files:**

- Data: `Promise.all([getPlot(id), getPlan(id)])`; plot `not_found` → `notFound()`; plot unavailable → registry `ErrorPanel` ("Registry service is not answering" / "The plot's details can't be read. - Layout (top→bottom): "All farms" link, farm name (muted), "{plot name}, {crop name}" (22 px bold), `Hero`, `StaleNote` if `plan.stale`, "Next 7 days" heading, `WeekBars`.
- `Hero({day, plan})`: `Gauge` left (44 px wide, ≥150 px tall, ink frame; soil, water fill to `gauge().water`, dashed refill line at `gauge().refill`; `role="img"` with label "Soil water at end of today: {bucket_end_mm rounded} of {capacity rounded} mm; refill line at {threshold rounded} mm."), right: "Today, {formatDayShort}", answer 44 px/800 ("Water for {formatDuration}" or "No irrigation today"), `heroSubline`.
- `StaleNote({fetchedAt})`: refill-bg panel, refill left edge: "Based on an old forecast from {formatAge} ago: the weather provider isn't answering. These numbers may be off."
- `WeekBars({days, seasonNote})` client: grid of `days.length` columns (fixed 7-column grid so fewer days keep bar width); per day a `<button aria-pressed>` with `aria-label` "{formatDayLong}, water {formatDuration}" / "{formatDayLong}, no irrigation"; label above `formatClock` or "none"; bar height from `barHeights` (min 2 px line for 0); first bar ink, others water; stale → striped; below: "Today"/`formatWeekday`, rain `formatMm` mm in water colour when `rain_mm ≥ 0.1`. Selected day (default index 0) → details panel: `formatDayLong`; "Run time {formatDuration | No irrigation}"; "{formatLitres} litres ({irrigation_mm} mm of water)"; "Crop use {etc_mm} mm (Kc {kc} × ET0 {et0_mm} mm)"; "Rain {rain_mm} mm"; "Soil water at end of day {bucket_end_mm} of {capacity} mm"; "Old forecast" if stale. Legend: "Run time in hours:minutes. Blue under a day is forecast rain." + " Striped: old forecast." when stale. `seasonNote` shown above the legend when non-null. Keyboard: Tab between bars, Enter/Space selects, visible outline on focus and on the selected bar.
- `loading.tsx`: skeleton hero panel with "Working out today's plan…".
- `not-found.tsx`: "No plot with this id." + link "All farms".
