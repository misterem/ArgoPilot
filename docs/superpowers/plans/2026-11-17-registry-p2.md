# Registry for P2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `setup_db.py` loads all 15 seed rows; settings come from a pydantic-settings `config.py` with `DATABASE_URL` required at startup; NFR-2.2 measured on local PostgreSQL.

**Architecture:** New `config.py` owns reading `.env`/environment; `db.py` asks it for the URL; `main.py` and `scripts/setup_db.py` fail fast with a clear message when the URL is missing. `setup_db.py` adds `demo.sql` to what it loads in its single transaction.

**Tech Stack:** FastAPI, SQLAlchemy 2.0 Core, psycopg 3, pydantic-settings 2, pytest, uv.

**Spec:** `docs/superpowers/specs/2026-11-17-registry-p2-design.md` (and `tasks/p2.md`, registry section and "Global configurations").

All commands run from `services/registry-service`. Work on branch `p2`.

## Global Constraints

- Code must run on Python 3.12 and 3.14.
- "A service starts with a clear error when a required variable is missing, not crash later on the first request."
- "Each Python service reads its settings with pydantic-settings, in one `config.py` file."
- "Each service has a `.env.example` with every variable and a safe example value. Commit it." `.env` is never committed.
- A real environment variable beats `.env` (unchanged behaviour).
- No new endpoints, fields, or schema changes. No judgment-log entry.
- The whole suite passes on SQLite, and with `TEST_POSTGRES_URL` set.

## Review Focus

1. **A developer's own `.env` (e.g. pointing at Postgres) must not change test results.** Config tests isolate the env file; the `client` fixture always sets `DATABASE_URL`. Test: `test_env_file_is_read` / `test_missing_url_raises_config_error` point `config.ENV_FILE` at a temp path.
2. **`DATABASE_URL=` (empty) counts as missing**, not as a URL. Test: `test_empty_url_is_missing` (Task 1).
3. **Unrelated variables in `.env` don't stop startup** (later tasks add more vars to other services' files; people copy files around). Test: `test_unknown_env_vars_are_ignored` (Task 1).
4. **`setup_db.py` without any config** prints the clear message and exits non-zero, rather than a pydantic traceback. Test: `test_setup_without_config_exits_cleanly` (Task 1).
5. **Running setup twice** never duplicates seed rows: the second run refuses and changes nothing. Covered by the existing `test_setup_refuses_when_tables_exist` (kept in Task 2).

### Task 1: `config.py` with required `DATABASE_URL`

**Files:**
- Create: `config.py`
- Modify: `db.py` (drop `load_env`, `DEFAULT_DATABASE_URL`, the `dotenv` import; `database_url()` reads settings), `main.py` (startup check), `scripts/setup_db.py` (missing-config path), `tests/conftest.py`, `tests/test_config.py`, `tests/test_setup_db.py`, `pyproject.toml` + `uv.lock`, `.env.example`

**Interfaces:**
- Produces (in `config.py`):
  - `SERVICE_DIR: Path` (the service folder), `ENV_FILE: Path = SERVICE_DIR / ".env"`
  - `class ConfigError(Exception)`; its message is `"DATABASE_URL is not set. Copy .env.example to .env in services/registry-service, or set it in the environment."`
  - `class Settings(BaseSettings)`: `database_url: str = Field(min_length=1)`; `model_config = SettingsConfigDict(env_file_encoding="utf-8", extra="ignore")`
  - `load_settings(env_file: Path | None) -> Settings` — builds `Settings(_env_file=env_file)`; converts a `pydantic.ValidationError` into `ConfigError` (message above, naming every missing/empty field if more are added later).
  - `get_settings() -> Settings` — `@functools.cache`d, calls `load_settings(ENV_FILE)` reading the module global at call time (so tests can monkeypatch `config.ENV_FILE`). Tests reset it with `config.get_settings.cache_clear()`.
- `db.database_url() -> str` keeps its name and returns `config.get_settings().database_url`. `db.SERVICE_DIR` stays (tests use it); it may re-export `config.SERVICE_DIR`.

```python
import pytest
import config

def test_env_file_is_read(tmp_path, monkeypatch):
    monkeypatch.delenv("DATABASE_URL", raising=False)
    (tmp_path / ".env").write_text("DATABASE_URL=sqlite:///from-file.db\n")
    assert config.load_settings(tmp_path / ".env").database_url == "sqlite:///from-file.db"

def test_real_env_beats_env_file(tmp_path, monkeypatch):
    monkeypatch.setenv("DATABASE_URL", "sqlite:///from-env.db")
    (tmp_path / ".env").write_text("DATABASE_URL=sqlite:///from-file.db\n")
    assert config.load_settings(tmp_path / ".env").database_url == "sqlite:///from-env.db"

def test_missing_url_raises_config_error(tmp_path, monkeypatch):
    monkeypatch.delenv("DATABASE_URL", raising=False)
    with pytest.raises(config.ConfigError, match="DATABASE_URL"):
        config.load_settings(tmp_path / "absent.env")

def test_empty_url_is_missing(tmp_path, monkeypatch):
    monkeypatch.delenv("DATABASE_URL", raising=False)
    (tmp_path / ".env").write_text("DATABASE_URL=\n")
    with pytest.raises(config.ConfigError, match="DATABASE_URL"):
        config.load_settings(tmp_path / ".env")

def test_unknown_env_vars_are_ignored(tmp_path, monkeypatch):
    monkeypatch.delenv("DATABASE_URL", raising=False)
    (tmp_path / ".env").write_text("DATABASE_URL=sqlite:///x.db\nWEATHER_URL=http://x\n")
    assert config.load_settings(tmp_path / ".env").database_url == "sqlite:///x.db"

def test_database_url_comes_from_settings(monkeypatch):
    monkeypatch.setenv("DATABASE_URL", "sqlite:///via-settings.db")
    config.get_settings.cache_clear()
    assert db.database_url() == "sqlite:///via-settings.db"
```
